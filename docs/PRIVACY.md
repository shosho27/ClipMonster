# ClipMonster Privacy Policy

Last updated: 21 September 2026

ClipMonster is a macOS menu bar clipboard manager (bundle ID `com.sashornock.ClipMonster2`). It stores a history of items you copy so you can find and reuse them later.

## What is stored

All of the following stay on this Mac:

- Text, images, and file references you copy.
- Screenshot PNGs in ClipMonster's storage folder. The default is `~/Library/Application Support/ClipMonster 2.0/` in the Direct edition, or the equivalent path inside the App Sandbox container in the Mac App Store edition. You can choose a different folder in Preferences.
- Optional on-device OCR text extracted from images with Apple Vision.
- Preferences in UserDefaults (shortcuts, history limits, pause, auto-OCR, auto-paste, storage path, welcome flag).
- A security-scoped bookmark for a custom storage folder, and optional bookmarks for file clips in `index.json`, so a sandboxed build can keep access after relaunch.

## What is not collected

ClipMonster does not create an account, does not include analytics or crash reporters, and does not send clipboard contents or any other data over the network. The bundled privacy manifest (`PrivacyInfo.xcprivacy`) declares that tracking is off.

## Secrets

These copies are not added to history:

- Pasteboard items marked `org.nspasteboard.ConcealedType`, `org.nspasteboard.TransientType`, or `org.nspasteboard.AutoGeneratedType`.
- Copies made while a known password manager is frontmost (1Password, Bitwarden, LastPass, Dashlane, KeePassXC, Apple Passwords, Keychain Access, Microsoft Authenticator, Authy).
- Short password-like strings (8–64 characters, no spaces, mixing letters, digits, and a symbol).

You can pause capture at any time (header button or Preferences) and purge stored history from Preferences. Purge asks for confirmation and then deletes ClipMonster's index and the PNG files it created.

## Permissions

Global shortcuts use system hotkeys and do not require Accessibility.

The **Direct** edition can optionally simulate ⌘V (auto-paste and CLI path paste). That uses Accessibility, which you grant in System Settings. The **Mac App Store** edition does not simulate keystrokes: it copies the item and you press ⌘V.

Start at login uses the system Login Items API. The Direct edition may fall back to a LaunchAgent in `~/Library/LaunchAgents/` if that API is unavailable. The Store edition never writes a LaunchAgent.

## Your control

You choose whether history survives a reboot, where files are stored, whether capture is paused, and when to delete items. Purging history removes ClipMonster's index and the PNG files it created. Unrelated files in a custom folder are left alone.
